# SkillForge Technologies & Solutions Ltd — Frontend Website

Frontend-only corporate website built with Next.js and React.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes

- The company logo is currently represented by a temporary SF mark so the final logo can be dropped in later.
- Company email addresses in the contact section are placeholders and should be replaced with the official addresses.
- No backend, CMS, authentication, database, or API integration is included.
- All page interactions are frontend-only.
